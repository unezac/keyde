🎓 HOW IT WORKS:

1. App shows German sentence from database
2. User types the sentence character by character
3. Each character is validated in real-time
4. Correct characters turn green
5. Wrong characters turn red
6. Progress bar fills as user types
7. When sentence is complete:
   - WPM calculated
   - Accuracy calculated
   - German audio plays (auto or manual)
   - After 1.2 seconds, next sentence loads
8. Statistics are tracked in browser memory
9. Achievements unlock when criteria met
10. Everything saved to LocalStorage!

================================================================================
                         DATA FLOW VERIFIED
================================================================================

Request Path:
  1. Frontend sends: GET /api/sentences/random?level=B2
  2. Backend receives: Query parameters parsed
  3. Database query: Select random sentence filtered by level
  4. Response: JSON with fields (german_text, english_translation, etc.)
  5. Frontend receives: JSON response
  6. Normalization: normalizeApiSentence() maps fields
  7. Display: renderSentence() shows user the sentence

Field Mapping (Automatic):
  Backend Field          →  Frontend Field
  german_text            →  german
  english_translation    →  en
  arabic_translation     →  ar
  level                  →  level
  id                     →  id

Error Handling:
  ✅ Network error     → Fallback sentences used
  ✅ API 404 response  → Default fallback displayed
  ✅ Invalid JSON      → Graceful error handling
  ✅ No sentences      → Fallback array shown

KeyGermany - Project Goals & Requirements
🎯 Main Goal
Build a German typing speed trainer where learners practice typing German B2-level sentences while listening to native pronunciation. The app combines typing practice with language learning.

📋 Core Functional Requirements
1. Frontend (User Interface)

Clean, Modern Design: Blue & white color scheme, centered layout
Header:

Left: Logo/icon
Center: "KeyGermany" branding
Right: Settings (Language: English/Arabic)


Main Content Area:

Display ONE German sentence (B2 level) in large, bold font
Show translation below (English or Arabic based on settings)
Input field where user types the German sentence
Virtual keyboard display at bottom (reference)


Real-time Feedback:

✅ Typed text turns GREEN when correct
❌ Typed text turns RED when there's a typo
Auto-complete triggers when sentence is typed correctly


Audio/Speech:

When sentence is completed correctly, automatically play German pronunciation (Web Speech API, de-DE)
Clear audio button for manual replay



2. Backend (FastAPI + PostgreSQL)

Endpoints:

GET /api/sentences/random - Return random B2 German sentence with translations
GET /api/sentences - Get all sentences (with filtering by level)
POST /api/sentences - Add new sentence (admin)


Database Schema:

id (Primary Key)
german_text (The German sentence)
english_translation (English translation)
arabic_translation (Arabic translation)
level (A1, A2, B1, B2, C1, C2)
difficulty_score (1-10)
created_at, updated_at timestamps



3. User Workflow

User loads the app
Random German sentence appears
User sees English OR Arabic translation (based on settings)
User types the German sentence in the input field
Real-time validation:

If typing is wrong → text turns RED
If typing is correct → text turns GREEN


When sentence is fully typed correctly:

Audio plays German pronunciation automatically
After 1 second delay, input clears
Next sentence loads automatically


User can continue indefinitely or check stats
